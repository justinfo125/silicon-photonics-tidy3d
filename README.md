## Overview

This project implements two foundational silicon photonics simulations using the Tidy3D Python API:

1. **SOI Ridge Waveguide** — single-mode TE propagation analysis  
2. **Directional Coupler** — evanescent coupling gap sweep extracting coupling length Lc

Both simulations target the standard 450 nm × 220 nm SOI platform used in production photonic integrated circuits at GlobalFoundries, IMEC, and AIM Photonics — the same platform underlying Ayar Labs' TeraPHY co-packaged optical interconnect chiplets.

## Physical Background

### SOI Waveguide (Sim 1)

A silicon ridge waveguide confines light through total internal reflection at the Si/SiO₂ and Si/Air interfaces. The large index contrast (Δn ≈ 2.0) enables sub-micron optical confinement — orders of magnitude tighter than optical fiber.

The 450 × 220 nm cross-section supports exactly one TE mode at 1550 nm. This single-mode condition is critical for coherent applications (no inter-modal dispersion) and is verified by the simulation's mode solver, which finds neff ≈ 2.4 for the fundamental TE₀ mode.

**Key outputs:**
- Ex field profile (dominant TE polarization component)
- Total intensity |E|² confirming tight lateral confinement
- Propagation power curve confirming negligible radiation loss

### Directional Coupler (Sim 2)

Two parallel waveguides separated by a narrow gap exchange power evanescently. The physics is elegantly described by supermode theory:

```
Lc = λ₀ / (2 · |neff,even − neff,odd|)
```

where `neff,even` and `neff,odd` are the effective indices of the symmetric and anti-symmetric supermodes of the coupled waveguide system. As the gap increases, the evanescent overlap — and therefore Δneff — decreases exponentially, making Lc grow exponentially with gap distance.

**Key outputs:**
- Coupling length Lc as a function of gap (100–200 nm)
- Exponential fit characterizing the evanescent decay constant
- Δneff vs gap on semi-log axes (verifies exponential relationship)
- Top-down field visualization showing sinusoidal power transfer

## Running the Simulations

### Quick geometry check (no API key needed)

```bash
cd simulations/
python sim1_waveguide.py --mode dryrun
python sim2_directional_coupler.py --run dryrun
```

### Cloud run (GPU-accelerated, ~2–5 min per simulation)

```bash
python sim1_waveguide.py --mode cloud
python sim2_directional_coupler.py --method supermode --run cloud
```

### Full FDTD coupler sweep (more compute, more visual output)

```bash
python sim2_directional_coupler.py --method fdtd --run cloud
```

## Methods

### Why Tidy3D?

Tidy3D is a GPU-accelerated FDTD solver with a clean Python API used in industry at companies including Ayar Labs, HyperLight, and Flexcompute's own photonics R&D. Compared to MEEP:

- **10–100× faster** on equivalent problems (GPU vs CPU)
- **Cloud-native** — no local hardware requirements
- **Strong Python API** — simulation objects are immutable, serializable, and version-controlled
- **Built-in mode solver** — `tidy3d.plugins.mode.ModeSolver` runs eigenmode analysis directly

### Coupling length extraction (two methods)

**Supermode method** (Sim 2, `--method supermode`):  
Solves for even and odd supermode neff at the coupler cross-section, then computes Lc = λ/(2·Δneff). Fast (~seconds per gap value) and exact within FDTD accuracy.

**FDTD method** (Sim 2, `--method fdtd`):  
Runs full 3D simulation, monitors power in each waveguide as a function of propagation distance z, identifies Lc as the z where P_B is first maximized. Slower but provides the power transfer sinusoid as a direct visual output.

## Background

This project was developed as part of ongoing silicon photonics research in the Computational Electronics Laboratory at Boston University, and as a portfolio demonstration of practical FDTD simulation skills relevant to silicon photonics process engineering and device characterization roles.

The simulation platform mirrors production conditions at SOI foundries (GF 45SPCLO, IMEC iSiPP50G), and the directional coupler geometry is directly analogous to the wavelength-selective couplers used in microring resonator-based WDM systems like the Ayar Labs TeraPHY chiplet.
